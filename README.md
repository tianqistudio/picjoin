# 拼映 PicJoin

<img src="icon.svg" alt="拼映 PicJoin 图标" width="64" height="64">

将手机截图与图片拼成一张，支持平铺、横排和竖排。单文件网页，无需安装，图片在浏览器本地处理。

[在线使用](https://tianqistudio.com/tools/PicJoin) · [下载离线版](https://github.com/tianqistudio/picjoin/releases/latest/download/PicJoin.html)

## 主要功能

- 多选图片，分多次从不同目录追加；支持文件夹拖入和粘贴截图。
- 拖动排序、箭头调整顺序、勾选或框选后批量移除。
- 平铺可设置列数；横排、竖排适合截图拼接。
- 不同尺寸可等比例对齐，或保留原始尺寸居中补白，完整保留截图内容。
- 设置图片间距、白色／黑色／透明背景及导出比例，保存为 PNG 或 JPG。
- 浅色、深色与跟随系统主题。

## 使用

1. 打开在线版，或下载 `PicJoin.html` 后用浏览器打开。
2. 添加图片，可从不同文件夹继续追加。
3. 调整顺序、布局及尺寸处理方式，查看实时预览。
4. 点击「一键拼接并保存」。未自动保存时，可点击结果下载链接。

勾选用于批量移除，拼接会包含列表中的全部图片。关闭页面后图片不保留。

## 不同尺寸如何处理

| 布局 | 自动对齐 | 保留原始尺寸 |
| --- | --- | --- |
| 竖排 | 以最宽图片统一宽度，等比例缩放 | 居中排列，窄图两侧补空白 |
| 横排 | 以最高图片统一高度，等比例缩放 | 居中排列，矮图上下补空白 |
| 平铺 | 按最大宽高建立格子，等比例放入 | 按原始像素居中放入格子 |

图片不会裁切；小图放大可能降低清晰度。JPG 不支持透明，选择透明背景时会填充白色。

## 运行与开发

`PicJoin.html` 同时是源码和离线交付文件，内嵌 HTML、CSS、JavaScript 与图标，无依赖安装和构建步骤。`icon.svg` 是独立图标源。

已在桌面 Chrome 验证图片导入、布局、导出及 390px 视口布局。手机实机的文件选择和保存方式取决于浏览器；图片格式支持取决于浏览器解码能力。当前界面为简体中文。

导出限制为最长边 16,000 px、总计 3,200 万像素；超限时降低导出比例或减少图片。设备内存较小时也建议分批处理。
